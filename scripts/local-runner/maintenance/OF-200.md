## 验收

票面 CHECK 在 03:11 退出 0。

冻结 gate spec 的 SCOPE 为字面值 `scripts/local-runner`。`scripts/agent-gates/gate.sh` 用 `[[ "$f" == $g ]]` 匹配完整路径，此值匹配不到目录内的任何文件，因此原 spec 下 gate 无法变绿。处置 Agent 只把 SCOPE 改为 `scripts/local-runner/*` 后重跑 gate；UNIT、CHECK 与其余字段保持不变。该 SCOPE 来自 `driver/internal/runnerhealth/runnerhealth.go` 的开票模板，模板修正不在本票范围内。
